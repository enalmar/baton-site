Support

Most problems are one of these four.

The other Mac never appears

Both Macs need the same code and Local Network permission, in System Settings → Privacy & Security → Local Network. They also need to be on the same network; some guest and office networks block discovery.

A peripheral is attached to no Mac

A released Magic device stops listening after a while. Switch it off and on, then choose Bring to This Mac.

"It may be held by another Mac"

That Mac still has the link. Send the device across from its own Baton menu, or disconnect it in its Bluetooth settings.

The peripheral isn't listed

Baton lists only devices already paired with the Mac you're on. Pair it once in System Settings → Bluetooth.

Sending a report

In Console, filter by com.eam.baton, reproduce the problem, and copy what appears. That plus your macOS version is usually enough.

Email

support@batonapp.uk. For licence questions, write from the address you paid with.
